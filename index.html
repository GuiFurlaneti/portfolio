01 Projeto principal

Campin — Plataforma de Gestão Operacional

  • Projeto autoral
  • Em uso na operação da empresa

Plataforma web que idealizei e desenvolvo a partir de necessidades reais da Classe A, empresa onde trabalho. O planejamento de regiões, as fotos enviadas pelas equipes de campo e o acompanhamento das campanhas ficavam em ferramentas separadas, e a consolidação para prestar contas era manual.

Sou responsável pelo frontend, pela API REST e pela modelagem do banco de dados, que reúnem em uma única aplicação o cadastro de campanhas, a gestão das equipes e os registros feitos em campo.

Case técnico em PDF (abre no GitHub em nova aba) Showcase no GitHub (abre em nova aba)

Prévia de 22 segundos com navegação pelos módulos. O case em PDF (13 páginas) detalha problema, solução e decisões técnicas; o código-fonte é privado.

Imagens demonstrativas. Dados fictícios, sem relação com operações reais.

Funcionalidades

  • Campanhas com calendário, clientes, lojas e equipes
  • Autenticação e permissões por perfil verificadas na API
  • Registro de turnos e fotos pelos promotores em campo
  • Mapa ao vivo das equipes e dados geográficos com PostGIS
  • Relatórios com exportação em CSV e PDF e fotos em ZIP
  • Portal do cliente com campanhas, evidências e mapa

Arquitetura

Frontend em React (PWA) hospedado na Cloudflare, API REST em Node.js com Fastify hospedada no Render e banco PostgreSQL com PostGIS para dados geográficos.

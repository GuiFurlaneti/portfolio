Campin — Plataforma de Gestão Operacional

Projeto autoral Software em uso real

Plataforma de gestão operacional que idealizei e desenvolvo a partir de necessidades identificadas na Classe A.

Centraliza informações de campanhas, equipes e atividades de campo, integrando frontend, APIs REST e banco de dados em uma aplicação web utilizada em operações reais.

  • Gestão de campanhas
  • Controle de acesso e perfis de usuário
  • Registros operacionais e fotográficos
  • Informações geográficas em mapa
  • Relatórios e acompanhamento das operações

Arquitetura: frontend em React, API REST em Node.js com Fastify e banco PostgreSQL com PostGIS para dados geográficos. Hospedagem em Cloudflare e Render.

  • React
  • JavaScript
  • Node.js
  • Fastify
  • PostgreSQL
  • PostGIS
